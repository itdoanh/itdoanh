# Tết 2026 - Chúc Mừng Năm Mới 🎊

Dự án chúc mừng Tết Nguyên Đán 2026 (Bính Ngọ) - Năm Ngựa

## Giới thiệu

Trang web chúc mừng năm mới với hiệu ứng đẹp mắt:
- 🏮 Đèn lồng đỏ bay lơ lửng
- 🎆 Pháo hoa tương tác
- 🌸 Hoa rơi lãng mạn
- 💰 Lời chúc tài lộc, sức khỏe, hạnh phúc

## Xem demo

Mở file `index.html` trong trình duyệt để xem trang chúc Tết.

## Tính năng

- Thiết kế responsive, hoạt động tốt trên mọi thiết bị
- Hiệu ứng pháo hoa có thể bắn tương tác
- Đèn lồng và hoa rơi tự động
- Màu sắc đỏ vàng truyền thống của Tết

## Công nghệ

- HTML5
- CSS3 (animations, gradients)
- JavaScript (canvas-confetti)
- Google Fonts
